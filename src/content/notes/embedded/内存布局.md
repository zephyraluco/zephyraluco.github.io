## 物理内存映射

以 **STM32F103C8T6** 为例，其拥有 **64KB FLASH** 和 **20KB SRAM**：

```mermaid
flowchart LR
    subgraph FLASH["FLASH (64KB) 0x08000000 ~ 0x0800FFFF"]
        direction TB
        F1[.isr_vector<br/>中断向量表]
        F2[.text<br/>代码]
        F3[.rodata<br/>常量/字符串]
        F4[.rti_fn<br/>自动初始化表]
        F5[.finsh_syscall<br/>FinSH 命令表]
        F6[.ARM.exidx<br/>异常索引]
        F7[.init_array/.fini_array<br/>构造/析构表]
        F8[.data LMA<br/>数据段加载地址]
    end
    subgraph RAM["SRAM (20KB) 0x20000000 ~ 0x20004FFF"]
        direction TB
        R1[.data<br/>已初始化全局变量]
        R2[.bss<br/>未初始化全局变量<br/>含 RT-Thread 堆/线程栈]
        R3[._user_heap_stack<br/>保留区]
        R4[MSP 栈<br/>主栈 向下生长]
    end
```

## 内存分配结构图

下图展示程序在地址空间中的分配情况（从上到下地址递减，高地址在上）：

```mermaid
flowchart LR
    subgraph MEM["程序内存分配结构"]
        direction TB
        STACK["栈 Stack<br/>↓ 向下增长"]
        HEAP["堆 Heap<br/>↑ 向上增长"]
        BSS["bss<br/>未初始化全局变量"]
        DATA["data<br/>已初始化全局变量"]
        TEXT["text<br/>代码段"]
        STACK ~~~ HEAP ~~~ BSS ~~~ DATA ~~~ TEXT
    end
    DIR["▲ 高地址<br/>│<br/>地址递增<br/>│<br/>▼ 低地址"]
    MEM ~~~ DIR
```

| 段 | 所在存储器 | 内容 | 初始化方式 |
|----|-----------|------|-----------|
| `text` | FLASH | 程序指令（`.text`）与只读常量（`.rodata`） | 出厂即固化，无需初始化 |
| `data` | FLASH（LMA）→ SRAM（VMA） | 已初始化全局/静态变量 | 启动时由 `Reset_Handler` 从 FLASH 拷贝到 SRAM |
| `bss` | SRAM | 未初始化全局/静态变量 | 启动时由启动代码清零 |
| 堆 | SRAM | `malloc` / RT-Thread 动态内存 | 运行时向上增长，堆顶地址 `_end` 起 |
| 栈 | SRAM | 函数调用帧、局部变量 | 向下增长，Cortex-M 复位后指向 `_estack`（SRAM 顶端） |
