## ROS-`catkin`构建系统
- **初始化工作空间：**  
    ROS的构建工作空间通常有三部分：`src`（源码文件夹）、`build`（编译文件夹）、`devel`（开发文件夹）。你可以使用`catkin_init_workspace`和`catkin_make`，或者`catkin_tools`来初始化和构建工作空间。
```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/src
catkin_init_workspace
```
- **构建工作空间：** 在`catkin_ws`工作空间中，通过`catkin_make`命令来构建工作空间。这个命令会编译源代码并将其安装到`devel`目录中。
```bash
cd ~/catkin_ws
catkin_make
```
- **构建特定的包：** 使用`catkin_make`时，也可以指定只构建某些特定的包，例如：
```bash
catkin_make --pkg package_name
```
- **构建环境配置：** 在每次启动ROS工作空间时，使用以下命令来设置环境变量，使得ROS可以找到开发环境中的包。
```bash
source devel/setup.bash
```

## ROS2-`colcon`构建系统
ROS 2使用`colcon`作为其标准的构建工具。`colcon`支持多个构建系统，包括`CMake`、`ament`、`Python`等，并且能够同时管理多个包的构建。它具有更强的可扩展性和支持的功能，并且更适合于ROS 2的分布式、异步架构。
- **初始化工作空间：** ROS 2的工作空间结构类似于ROS 1，但无需初始化。
- **构建工作空间：** 使用`colcon build`命令来构建工作空间：
```bash
cd ~/ros2_ws
colcon build
```
- **构建特定的包：** `colcon`允许你只构建特定的包，而不是整个工作空间：
```bash
colcon build --packages-select package_name
```
- **安装和源环境：** 在构建之后，需要使用`source`命令来加载环境设置，使得你的终端能够找到相关的包和库。
```bash
source install/setup.bash
```
