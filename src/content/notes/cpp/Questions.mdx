## main(),wmain(),winMain(),wWinMain()

main()函数是console程序的入口。而wmain是unicode字符集环境下的console入口函数。 winMain()是win32 Application的入口函数。而wWinMain()是unicode环境下的win32 Application的入口函数。

## 如何在 main 函数之前运行执行函数？

1. gcc 拓展，使用\_\_attribute((constructor))来声明 main 之前的函数，\_\_attribute((destructor))来声明 main 函数之后的函数。
2. 使用全局变量先于 main 函数的初始化的特性，来通过调用函数初始化全局变量使得函数 main 之前执行。

## struct 和 class 的区别

- C++中的 struct 可以包括成员函数，可以实现继承，可以实现多态。
- struct 默认访问权限是 public，class 是 private。
- class 可以使用模板，而 struct 没有。

注：C++中有 struct 是为了对 C 兼容，更好的移植代码。

## typedef和typename关键字

- typedef: 用于声明类型别名，`typedef int INT`
- typename: 用于声明模板参数或者标明内嵌依赖类型名

## C++中 0,NULL 和 nullptr 的区别？

1. `NULL` 是一个宏,本质上就是 0
2. `nullptr` 则是一个为 0 的指针，其类型为(T \*)0,T 为泛型

## C++引用和指针的区别

- **引用本质是指针常量**，也占用内存空间，但程序并不会按照普通的指针来处理，而是将引用看作对象本身。
- 对引用取地址时，编译器会会默认间接寻址，返回的是对象的地址。
- 相较于指针，引用会在编译期进行安全性检查和处理，以保证与指针的语义不同

## 拷贝构造函数被调用的时机？

1. 显式调用，`Test a(b);Test a=b;`
2. 将一个对象作为实参传递给非引用类型的形参，`Test a;func(a);`
3. 返回一个非引用类型的对象时，`Test func(){ Test a;return a; }`

## 移动构造和拷贝构造？

- 当类中未定义拷贝构造函数时，编译器会提供一个默认拷贝构造函数 **（浅拷贝）**，但如果类中有指针时，可能会发生重复释放的问题。
- 移动构造函数是为了解决自定义拷贝构造带来的问题 **（自定义常为深拷贝，会导致内存大量占用）**，使用`move`来转义对象的所有权。
- 当同时定义了移动构造和拷贝构造时，默认调用移动构造函数。

## C++强制类型转换

1. `static_cast<type> variable`: 即普通的强制类型转换
2. `const_cast<type> variable`: 去除指向常量对象的指针或引用的常量性，其对象必须是**指针或引用**
3. `reinterpret_cast<type> variable`: 将**任意指针转为其他类型的指针**，也可以进行**整型和指针**之间的转换
4. `dynamic_cast<type> variable`: 用于派生类的向上转型和向下转型，相比直接转型添加了类型检查，其对象必须是**指针或引用**

## 向上转型和向下转型

- 向上转型：派生类对象，指针或引用传给父类，保留基类中的非虚函数和成员变量，以及子类中的虚函数
- 向下转型：还原向上转型

## 类的静态成员变量和函数

- 类的静态成员由类的所有对象共享，因此不能在类的内部定义
- 类的静态函数没有this指针，不能返回非静态成员，可以被类本身和对象所调用
- 类的静态函数可以直接访问该类的静态成员和静态函数，但不能直接访问非静态成员和函数，需要传入具体的对象名称
