> 学习stm32主要是为了了解常见的通信方式，因此关于其他嵌入式的内容仅作简单说明

## STM32F103C8T6 结构

![alt text](/images/stm32-struct.png)

### 核心处理单元

- **Cortex-M3**: 由 ARM 设计的 32 位 RISC 处理器内核。
- **ICode 总线**: 指令总线。用于内核从 Flash 存储器中取指令。
- **DCode 总线**: 数据总线。用于内核从 Flash 中读取常量数据（如编译好的只读变量）。
- **System 总线**: 系统总线。用于内核访问 SRAM（内存）和外设寄存器。

### 总线与控制

- **总线矩阵 (Bus Matrix)**: 协调内核和 DMA 轮流访问内存或外设，确保数据传输不冲突。
- **AHB 系统总线**: 高速总线（Advanced High-performance Bus）。连接了总线矩阵和低速总线桥，是连接高速外设（如 RCC、SDIO）的骨干。
- **DMA 1 / DMA 2 (Direct Memory Access)**: 直接存储器访问控制器。
  - **作用**：它可以在不占用 CPU 的情况下，直接在内存和外设之间搬运数据（例如将 ADC 采集的数据直接存入 SRAM）。
  - 图中可以看到 **DMA 请求** 信号线，说明外设可以“主动”要求 DMA 搬运数据。
- **复位和时钟控制 (RCC)**: 负责为每个外设分配时钟信号。在 STM32 中，任何外设使用前都必须先在 RCC 中开启时钟。

### 外设总线与外设

图右侧展示了通过**桥接 (Bridge)** 连接的两条主要外设总线，它们的速率不同：

#### APB2 总线 (高速外设)

通常运行在较高的频率，连接的外设包括：

- **GPIOA ~ GPIOG**: 通用输入输出端口。
- **ADC1/2/3**: 模数转换器。
- **USART1**: 高速串口。
- **SPI1**: 高速串行外设接口。
- **TIM1 / TIM8**: 高级控制定时器（常用于电机控制 PWM）。
- **AFIO**: 复用功能 I/O 锁定和重映射控制。

#### APB1 总线 (低速外设)

频率上限通常是 APB2 的一半，连接的外设包括：

- **TIM2 ~ TIM7**: 通用定时器。
- **USART2 ~ 5 / UART4**: 普通串口。
- **I2C1 / I2C2**: 串行通信接口。
- **USB / bxCAN**: 通信接口。
- **DAC**: 数模转换器。
- **PWR / BKP**: 电源控制和备份寄存器。
- **WWDG / IWDG**: 看门狗定时器。

## GPIO 结构

![alt text](/images/gpio-struct.png)

### GPIO 输入

| **模式**                  | **性质**              | **特点**                                                                | **应用场景**                                 |
| ------------------------- | --------------------- | ----------------------------------------------------------------------- | -------------------------------------------- |
| <nobr>**浮空输入**</nobr> | <nobr>数字输入</nobr> | 电压状态完全由外部驱动决定。若外部悬空，**电平随机跳变**                | 外部已有强驱动的数字信号（如 UART 接收引脚） |
| **上拉输入**              | 数字输入              | 在无外部信号输入时，引脚默认保持**高电平**                              | 按键检测（按键另一端接地，按下为低）         |
| **下拉输入**              | 数字输入              | 在无外部信号输入时，引脚默认保持**低电平**                              | 高电平检测（检测外部高脉冲信号）             |
| **模拟输入**              | 模拟输入              | GPIO无效，引脚直接接入内部ADC，值为 0V 到 $V_{DD}$ 之间的**连续电压值** | 传感器采集（如读取电位器、光敏、温敏电阻）   |

### GPIO 输出

| **模式**                  | **性质**              | **特点**                                         | **应用场景**                          |
| ------------------------- | --------------------- | ------------------------------------------------ | ------------------------------------- |
| <nobr>**推挽输出**</nobr> | <nobr>数字输出</nobr> | 能主动输出高电平和低电平，驱动能力强             | 控制 LED、电机驱动、普通通讯          |
| **开漏输出**              | 数字输出              | 只能主动输出低电平；输出高电平需**外部上拉电阻** | $I^2C$ 通讯、实现“线与”逻辑、电平转换 |
| **复用输出**              | 数字输出              | 引脚不再受普通的 GPIO 寄存器控制                 | UART 串口、PWM 输出、SPI 通讯         |
| **复用开漏输出**          | 数字输出              | 结合了复用和开漏的特点                           | $I^2C$ 的 SCL/SDA 引脚                |
